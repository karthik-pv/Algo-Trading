## 2. Level semantics — RUN-DERIVED (2026-10-26, user-defined)

Supersedes the positional-SL / rejection-window-RL model (and the older still-locked
notes in the Oct 25 handoff — THIS is current truth):

- **RL (trigger zone)**: the rungs whose rejection STARTED the fall — touched and
  rejected during the rise into it AND within one **event-candle-range** of the
  rise's swing high (threshold = mean 5m bar range of the 5 candles ending at the
  turn). Several rungs can qualify; highest first.
- **SL (the stop)**: the rung bracketing the fall's LAST candle (low ≤ rung ≤ close
  there) — the 5m MACD2 cross-up at that candle confirms. Fallback label `LOW`
  (mirror: `HIGH`).
- **Crossed**: rungs BELOW the trigger zone crossed down during the fall (run low →
  zone bottom), excluding SL names. Up runs mirror (zone top → run high).
- **UP runs mirror fully**: SL = the support ZONE that triggered the rise (within one
  event-candle-range of the fall's swing low); RL = the single rung holding the
  rise's last candle (MACD2 cross-down confirms).

## 3. Runs — ONE signed `Run` column (2026-10-26)

- `3o_run` / `5o_run` replace `3o_uprun`/`3o_downrun` (+ = uprun, − = downrun,
  1 decimal; DRun = support − swing high, URun = resistance − swing low).
- The matrix has NO `uprun/downrun` columns any more (Grid labels: `Run`, and the
  MDERun session-label column is now `Session`).
- **Resolver** (was the cause of ~270 blanks; now only 26/349 blank = no MACD2 cross
  after the event AND a flat close):
  - direction = first 5m MACD2 cross after the event, else net event-close →
    session-close move;
  - confirming endpoint = next cross in the same direction, else the SESSION'S LAST
    BAR (unconfirmed moves run to the close — they count);
  - zone anchored on the previous opposite flip (or session open) — no
    containing-cycle requirement (mid-fall events work).
- Current matrix: **1,154 records x 47 cols** (down from 48 — one run column instead
  of two), sessions 2025-09-15 → 2026-10-26, 349 3OX-up / 805 unpaired 5OX-up /
  114 paired blocks. Runs: 157 up + 165 down + 26 blank (3O events).

## 5. Grid — tints (2026-10-26)

  no tint when blank.

  on the shared event-block cells. `rowTints()` in the 2PMM IIFE.
